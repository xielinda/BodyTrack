第一次打开？Mac → iPhone 使用步骤
  1. 把这个文件保存为 index.html。在 Mac 上双击，可先检查界面和手动记录。
  2. 在 GitHub 新建一个名为 bodytrack 的空 public 仓库，只上传这个 index.html，提交更改。公开的是源码，切勿上传身体照片或 CSV 记录。
  3. 仓库 Settings → Pages → Build and deployment：Source 选择 Deploy from a branch，Branch 选择 main，目录选择 / (root)，保存。
  4. 等待 Pages 显示发布成功及网址，用 iPhone 的 Safari 打开这个 HTTPS 网址（不要在聊天软件内嵌预览中测试）。
  5. 点击“开始扫描”，允许相机权限。拍完正面、侧面后相机会自动关闭。也可以拒绝相机，直接手动记录。
  6. 以后始终用同一个网址和浏览器。这里只提供网页，不需要安装原生 App。

如果被拒绝权限，请在 Safari 此网站的权限设置中允许相机，再重试。普通局域网 HTTP 地址无法可靠开启手机相机。

跟着理解代码：今天只学一个小改动

用 Mac 的纯文本编辑器打开文件（例如“文本编辑”切换到纯文本模式）。这不是 Python 文件，不在 IDLE 里运行。

  1. <body> 内是按钮、标题和表单，类似界面的清单。
  2. <style> 内控制颜色和布局。试着把 --green:#246a57 改成 --green:#365ba8，保存并刷新，按钮会变蓝。
  3. <script> 内是 JavaScript，浏览器直接运行。record 是一个对象，类似 Python 字典；records 是数组，类似 Python 列表；for...of 类似 Python 的 for 循环。
  4. 先读代码中“保存记录”这一段：读取输入 → 组成对象 → 加到数组 → 保存 → 更新画面。

验证清单：允许 / 拒绝相机、倒计时中关闭、正侧面拍摄、清除照片、空腰围被拦截、保存后刷新仍存在、删除、CSV 导出。真实 iPhone 的相机体验需要在你的设备上验证。

后续顺序：先完善手动记录 → 独立验证腰围估计算法 → 与软尺对照并评估多次重复测量误差 → 再决定是否做原生 App。单张照片无法直接提供可靠的真实围度。
